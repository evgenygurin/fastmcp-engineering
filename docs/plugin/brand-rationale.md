# Brand rationale

The mark is a compact engineering grid: three horizontal verification layers intersect two vertical boundary rails, with a centered node representing the MCP implementation under review.

The geometry communicates **structure + boundaries + verification**, which matches the Plugin's job: taking MCP engineering work through explicit architectural and quality gates.

The light and dark variants share identical geometry and differ only in background/foreground contrast. The compact icon removes all non-essential detail while preserving the grid-and-node relationship.
