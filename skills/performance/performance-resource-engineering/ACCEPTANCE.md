# Performance / Resource Acceptance

- [ ] Exact versions and official performance semantics researched.
- [ ] Workload and SLO model exists.
- [ ] Baseline measurements exist or limitation is documented.
- [ ] Bottleneck is evidence-based.
- [ ] Concurrency/resource budgets are explicit.
- [ ] No blocking I/O on async paths.
- [ ] DB queries/results are bounded and measured.
- [ ] Caches have isolation, invalidation, consistency and memory policy.
- [ ] Model/MCP fan-out respects deadline/retry/idempotency contracts.
- [ ] Optimization has measurable benefit.
- [ ] Regression tests/benchmarks exist where appropriate.
- [ ] Security and correctness were not weakened.
- [ ] Static quality gates pass.
- [ ] Architecture/reliability re-check passes.
