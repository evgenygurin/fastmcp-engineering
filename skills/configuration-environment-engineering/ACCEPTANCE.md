# Acceptance — Configuration and Environment Engineering

- [ ] Defines configuration sources, precedence, defaults, and required values.
- [ ] Separates build-time, deploy-time, and runtime configuration.
- [ ] Handles missing, malformed, conflicting, and secret values explicitly.
- [ ] Prevents secrets from entering source control, logs, or error output.
- [ ] Defines environment-specific verification and failure behavior.
- [ ] Stops when configuration behavior cannot be established from evidence; rejects invented behavior and escalates to the user instead of guessing.
