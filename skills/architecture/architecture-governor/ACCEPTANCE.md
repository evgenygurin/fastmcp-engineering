# Acceptance — Architecture Governor

- [ ] Produces an explicit architecture decision from requirements and constraints.
- [ ] Verifies responsibility boundaries and dependency direction.
- [ ] Evaluates simpler alternatives before introducing abstractions or patterns.
- [ ] Rejects architecture that violates the repository's SOLID/KISS/DRY/YAGNI or framework-boundary rules.
- [ ] Records assumptions, risks, trade-offs, and verification evidence.
