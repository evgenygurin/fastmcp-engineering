# Research-First Enforcement

This skill is not authorized to implement a FastMCP component until its research evidence exists.

Minimum evidence package:

1. exact FastMCP target version;
2. official documentation for the selected component;
3. relevant official examples;
4. source/tests for ambiguous or version-sensitive behavior;
5. MCP specification evidence where applicable;
6. first-party dependency evidence where applicable;
7. explicit component-selection decision;
8. architecture gate result;
9. verification plan.

The implementation agent must report each item. `unknown`, `not checked`, or `assumed from memory` is a research failure, not an approval state.
