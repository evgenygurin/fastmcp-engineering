# Acceptance — FastMCP Research

- [ ] Starts from the target FastMCP version and official documentation.
- [ ] Checks relevant official examples and source/API behavior when documentation is ambiguous.
- [ ] Separates documented facts, source-derived behavior, inference, and recommendation.
- [ ] Records version-sensitive compatibility constraints and migration risks.
- [ ] Produces reusable evidence artifacts for downstream skills.
- [ ] Stops when framework behavior cannot be established from evidence; rejects invented behavior and escalates to the user instead of guessing.
